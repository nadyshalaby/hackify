Sprint goal. Make performance a first-class, enforced concern across every hackify scanning surface (always-on rules, deterministic scout, reviewers, checklists), fix every defect the whole-plugin audit found, and ship it all as one combined 0.7.0 release.

What changed & why it matters

Hackify now treats performance the way it treats security: as a rule set that is always on. Every prompt carries a short list of performance guardrails, a full catalog of 95 known performance mistakes ships with the plugin, and a cheap deterministic "scout" scan looks for those mistakes at fixed points in every task. Code review grew a fourth parallel reviewer that focuses only on performance. A full audit of the plugin also fixed 25 issues and hardened the validators and hooks. The release checked itself with its own new tools — the scout and the new reviewer ran on this very change and passed — and everything ships together as version 0.7.0.
